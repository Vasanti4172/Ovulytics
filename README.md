# 🌸 OvulyticsPro

## 📌 Overview
OvulyticsPro is an AI/ML-based menstrual health analysis platform designed to go beyond traditional tracking apps. Unlike existing solutions that focus mainly on data logging, this system provides **interpretable insights** and **meaningful analysis** of menstrual cycle health.

The platform analyzes cycle stability using clinically relevant parameters and translates predictions into **user-friendly explanations**, empowering individuals to make informed health decisions.

---

## 🚀 Key Features

- 🔍 **Cycle Stability Analysis**
  - Classifies menstrual cycles as *Regular* or *Irregular* using machine learning.

- 🤖 **Machine Learning Model**
  - Uses a **Random Forest algorithm** trained on:
    - Cycle length
    - Ovulation indicators
    - Fertility metrics
    - Regularity index

- 📊 **Predictive Insights**
  - Provides next-cycle prediction based on observed patterns.

- 🧠 **Explainable AI**
  - Highlights key factors influencing predictions for better understanding.

- 🔐 **Secure Authentication**
  - Implements **JWT-based authentication** for user privacy and security.

- 🌐 **Scalable Architecture**
  - Built using:
    - Frontend: React
    - Backend: Flask
    - Database: MongoDB
    - Deployment: Docker

- 👤 **Personalized Tracking**
  - Login-based system for individualized health insights.
